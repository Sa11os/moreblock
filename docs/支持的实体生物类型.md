# MoreBlock 支持的实体生物类型 / Supported Entity AI Templates

本文件列出 MoreBlock 在导入自定义实体时，`ai_template` 字段当前已适配的**原版生物 AI 模板**。
填写时直接使用原版实体 id（如 `minecraft:zombie`）。未在列表中的 id 会回退为「空闲游荡」逻辑，并在日志中给出提示。

> 数据来源：[ImportedEntityAiTemplates.java](../src/main/java/me/sallos/moreblock/entity/ImportedEntityAiTemplates.java)

---

## 二、行为模板说明 / Behavior Templates

### 1. 被动型动物 / Passive Animal
适用：`cow`、`pig`、`sheep`、`chicken`、`mooshroom`

- 受到攻击时惊慌逃跑（PanicGoal）
- 主动远离玩家（AvoidEntityGoal）
- 随机在陆地游荡、避开水（WaterAvoidingRandomStrollGoal）
- 注视玩家、随机环顾（LookAtPlayerGoal / RandomLookAroundGoal）
- **无主动攻击行为**

### 2. 僵尸型 / Zombie
适用：`zombie`、`husk`

- 近战攻击（MeleeAttackGoal）
- 白天躲避阳光（FleeSunGoal）
- 随机游荡、注视玩家、随机环顾
- 仇恨目标：受伤反击 + 主动追击玩家（HurtByTargetGoal / NearestAttackableTargetGoal）

### 3. 蜘蛛型 / Spider
适用：`spider`、`cave_spider`

- 向目标扑跃（LeapAtTargetGoal）
- 近战攻击（MeleeAttackGoal）
- 随机游荡、注视玩家、随机环顾
- 仇恨目标：受伤反击 + 主动追击玩家

### 4. 骷髅型（远程）/ Skeleton (Ranged)
适用：`skeleton`、`stray`

- 远程射击攻击（RangedAttackGoal）
- 白天躲避阳光（FleeSunGoal）
- 随机游荡、注视玩家、随机环顾
- 仇恨目标：受伤反击 + 主动追击玩家

### 5. 末影龙型 / Ender Dragon
适用：`ender_dragon`

- 仅配置仇恨目标：受伤反击 + 主动追击玩家
- 不附加常规寻路/游荡 Goal（其飞行与阶段逻辑由专用 Boss 控制器处理）

## 三、使用示例 / Usage Example

在实体配置 JSON 中填写 `ai_template`：

```json
{
  "id": "blue_slime",
  "name": { "zh_cn": "蓝色史莱姆", "en_us": "Blue Slime" },
  "ai_enabled": true,
  "ai_template": "minecraft:zombie"
}
```

> 说明：
> - `ai_template` 留空或填写未适配的 id 时，实体会回退为「空闲游荡」逻辑。
> - 同一分组内的不同生物（如 `zombie` 与 `husk`）使用完全相同的行为模板。
> - `ai_enabled` 设为 `false` 时，将忽略本模板，实体仅保留基础生存行为。
