# MoreBlock 实体导入说明

这份说明面向想把 GeckoLib 实体模型直接放进 `config` 目录里使用的人。

当前这版先提供一个稳定的基础闭环：

- 从 `config/moreblock/entity` 扫描实体包
- 同时支持文件夹和 `zip`
- 自动生成运行时资源包
- 自动注册实体类型和刷怪蛋
- 自动生成示例配置与参数说明文件

## 1. 首次启动后会生成什么

第一次启动游戏后，模组会自动创建：

```text
config/moreblock/entity
config/moreblock/entity/.keep
config/moreblock/entity/README.txt
config/moreblock/entity/example/example.json
config/moreblock/entity/example/example.md
```

其中：

- `README.txt` 是目录说明
- `example.json` 是可直接复制的模板
- `example.md` 是每个字段的解释
- `example` 文件夹只作参考，不会被实际导入

## 2. 一个最基础的实体包

推荐目录结构：

```text
blue_slime/
├─ blue_slime.json
├─ blue_slime.geo.json
├─ blue_slime.animation.json
└─ texture.png
```

最少需要：

- 一个 GeckoLib `*.geo.json`
- 一张 `png` 贴图

可选文件：

- `*.animation.json`
- 一个配置 `*.json`

如果你不写配置文件，只放模型和贴图，MoreBlock 也会尝试按目录名推导一份基础导入定义；但长期维护时还是建议每个实体都写配置。

## 3. 推荐配置写法

```json
{
  "id": "blue_slime",
  "name": {
    "zh_cn": "蓝色史莱姆",
    "en_us": "Blue Slime"
  },
  "geo": "blue_slime.geo.json",
  "texture": "texture.png",
  "animation": "blue_slime.animation.json",
  "width": 0.9,
  "height": 0.9,
  "eye_height": 0.65,
  "max_health": 30.0,
  "movement_speed": 0.28,
  "follow_range": 24.0,
  "attack_damage": 4.0,
  "armor": 2.0,
  "knockback_resistance": 0.1,
  "tracking_range": 8,
  "update_interval": 3,
  "ai_enabled": true,
  "ai_template": "minecraft:zombie",
  "spawn_egg_primary_color": "#4b7cf0",
  "spawn_egg_secondary_color": "#d8e4ff",
  "show_in_moreblock_tab": true,
  "translucent": true
}
```

## 4. 字段说明

| 字段 | 是否推荐 | 说明 |
| --- | --- | --- |
| `id` | 推荐 | 实体短 ID，会参与注册名生成。 |
| `name.zh_cn` | 推荐 | 中文显示名。 |
| `name.en_us` | 推荐 | 英文显示名。 |
| `geo` | 推荐 | GeckoLib 实体模型文件名。 |
| `texture` | 推荐 | 贴图文件名。 |
| `animation` | 可选 | 动画文件名。不填时会使用内置默认 idle 动画。 |
| `width` | 可选 | 实体碰撞宽度。默认 `0.6`。 |
| `height` | 可选 | 实体碰撞高度。默认 `1.8`。 |
| `eye_height` | 可选 | 实体视线高度。默认按高度自动推导。 |
| `max_health` | 可选 | 最大生命值。默认 `20`。 |
| `movement_speed` | 可选 | 基础移动速度。默认 `0.2`。 |
| `follow_range` | 可选 | 目标跟随距离。默认 `16`。 |
| `attack_damage` | 可选 | 基础攻击伤害。默认 `2`。 |
| `armor` | 可选 | 基础护甲值。默认 `0`。 |
| `knockback_resistance` | 可选 | 击退抗性。默认 `0.2`。 |
| `tracking_range` | 可选 | 客户端追踪距离。默认 `8`。 |
| `update_interval` | 可选 | 实体同步更新间隔。默认 `3`。 |
| `ai_enabled` | 可选 | 是否启用 AI。默认 `true`。 |
| `ai_template` | 可选 | 原版生物 AI 模板 id，例如 `minecraft:zombie`。 |
| `spawn_egg_primary_color` | 可选 | 刷怪蛋主色。 |
| `spawn_egg_secondary_color` | 可选 | 刷怪蛋副色。 |
| `show_in_moreblock_tab` | 可选 | 是否把自动生成的刷怪蛋显示在 MoreBlock 创造栏。默认 `true`。 |
| `translucent` | 可选 | 是否按半透明材质渲染。默认 `true`。 |

## 6. zip 载入规则

实体导入和方块导入保持一致，也支持：

- 直接放一个实体包文件夹
- 直接放一个 `zip`
- `zip` 里套一层同名文件夹
- 外层 `zip` 里混合多个文件夹或子 `zip`

## 7. 导入后怎么测试

基础版会自动给每个导入实体注册一个刷怪蛋。

当前 `ai_template` 已适配一批常见原版模板：

- `minecraft:cow`
- `minecraft:pig`
- `minecraft:sheep`
- `minecraft:chicken`
- `minecraft:mooshroom`
- `minecraft:zombie`
- `minecraft:husk`
- `minecraft:spider`
- `minecraft:cave_spider`
- `minecraft:skeleton`
- `minecraft:stray`

未适配的原版 id 目前会回退为基础游荡逻辑，并在日志里给出提示。

建议测试顺序：

1. 把实体包放进 `config/moreblock/entity`
2. 重启客户端或服务器
3. 打开 MoreBlock 创造模式页签找刷怪蛋
4. 或用命令 `/moreblock entity list` 看有没有被识别
5. 主手拿着刷怪蛋时用 `/moreblock entity check` 查看来源

## 8. 当前基础版的定位

这一版重点先把“导入、注册、渲染、刷怪蛋、示例和文档”这条主链打通，方便你先把实体资源跑起来。

如果后面要继续扩，比较合适的方向包括：

- 更完整的动画控制
- AI、行为和交互配置
- 更细的分类与生成规则
- 客户端和服务端的实体包内容校验
